# {{appTitle}}

An Expo app with React Navigation, a typed `apiFetch<T>()` helper, a `useApi()` hook for loading and error states, and light and dark themes.

```bash
cp .env.example .env      # set EXPO_PUBLIC_API_URL
npx expo install --fix    # match native packages to your Expo SDK
npm start
```

Add an endpoint with `codz api add` and a screen with `codz screen add`. Check types with `npm run typecheck` and run the tests with `npm test`.
